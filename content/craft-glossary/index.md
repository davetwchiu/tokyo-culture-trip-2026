# 現場快速查閱

深入工序可參看[工藝史]({{ '/history/craft/' | relative_url }})。

| 日文 | 讀音 | 中文及觀察 |
|---|---|---|
| 漆 | うるし | 漆樹汁液固化形成塗層 |
| 木胎 | もくたい | 木質器身基礎 |
| 蒔絵 | まきえ | 漆黏附金銀粉形成裝飾 |
| 螺鈿 | らでん | 嵌貼貝片，留意虹彩 |
| 平塵 | へいじん | 古漆工金屬粉地紋；非後世平蒔繪同義詞 |
| 梨子地 | なしじ | 金屬粉與透明漆形成地紋 |
| 研出蒔絵 | とぎだしまきえ | 覆漆後研出紋樣 |
| 高蒔絵 | たかまきえ | 堆高裝飾後灑粉 |
| 彫漆 | ちょうしつ | 雕刻漆層 |
| 堆朱 | ついしゅ | 朱漆厚層雕飾 |
| 鎌倉彫 | かまくらぼり | 木胎雕刻後塗漆 |
| 鎗金 | そうきん | 線刻凹紋填金 |
| 沈金 | ちんきん | 刻紋填金，日本工藝名 |
| 填漆 | てんしつ | 刻紋填不同顏色漆並研平 |
| 蒟醤 | きんま | 刻紋填色漆等裝飾 |
| 截金 | きりかね | 切細金屬箔貼附成紋 |
| 金銅仏 | こんどうぶつ | 銅或銅合金鍍金佛像 |
| 押出仏 | おしだしぶつ | 薄金屬板錘打成浮雕 |
| 蝋型鋳造 | ろうがたちゅうぞう | 失蠟鑄造 |
| 鍍金 | めっき・ときん | 表面鍍層；具體工法依證據 |
| 刃文 | はもん | 刀刃淬火組織形成紋理 |
| 地肌 | じはだ | 鋼材鍛造與研磨的表面紋理 |
| 埴輪 | はにわ | 古墳周邊陶製形象 |
| 釉薬 | うわぐすり・ゆうやく | 燒成的玻璃質等表層 |
| 見当 | けんとう | 木版套印定位 |
| 馬連 | ばれん | 木版印刷在紙背施壓工具 |
| 暈し | ぼかし | 漸層摺印 |
| 唐物 | からもの | 中國等舶來物，語境隨時代變 |
| 取合せ | とりあわせ | 茶席各道具組合 |
| 作善 | さぜん | 宗教性善行，造像寫經供養等 |

同名技術在不同時代及地域有差異；以上為現場閱讀術語，不代替實物研究。
