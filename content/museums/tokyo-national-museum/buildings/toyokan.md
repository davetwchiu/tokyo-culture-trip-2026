**2026年11月30日至12月31日整館閉館，本次不能入內。** 以下保留作重訪及理解日本工藝的亞洲背景。1968年開館，谷口吉郎設計。

| 樓層／室 | 館方定位與觀察 |
|---|---|
| 1F・1 | 中國佛像；造像比例、石刻與金銅比較 |
| 2F・2 | Oasis教育空間 |
| 2F・3 | 西亞及埃及、印度、犍陀羅、西域；宗教形象跨地域轉化 |
| 3F・4 | 中國文明起源；早期玉、陶及考古 |
| 3F・5 | 中國青銅、墓葬、陶瓷、染織；禮器鑄造、釉與胎 |
| 3F・6 | 亞洲占卜教育體驗 |
| 4F・7 | 中國石刻畫；雕刻線條、拓片 |
| 4F・8 | 中國書畫、文人書齋；比較室町禪林 |
| 5F・9 | 中國漆工、清代工藝；彫漆、嵌飾 |
| 5F・10 | 朝鮮石器金屬器、王朝、陶瓷、佛教及朝鮮時代美術 |
| B1・11 | 高棉雕刻；砂岩及宗教建築 |
| B1・12 | 東南亞雕刻、印度及東南亞考古、陶瓷 |
| B1・13 | 亞洲染織、印度細密畫、民族文化 |

這館尤其適合比較根津唐物漆器、法隆寺佛像及五島高麗茶碗。不能把日本藝術視作封閉的技術傳統。日後可分兩次看，先中國與朝鮮，再西域、印度與東南亞。[樓層圖](https://www.tnm.jp/modules/r_free_page/?id=116&lang=ja) · [閉館通知](https://www.tnm.jp/modules/r_free_page/index.php?id=2002&lang=ja)
